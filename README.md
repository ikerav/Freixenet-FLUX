# Freixenet FLUX · Simulador interactivo

Simulador web desarrollado para el proyecto de Diseño Organizativo. Permite visualizar cómo podría adaptarse la estructura organizativa de Freixenet ante distintos escenarios de demanda, disponibilidad de producto e incertidumbre.

### Funcionamiento
- **Modo normal:** controles y visualizaciones en una misma pantalla.
- **Modo presentación:** gráficos y organigrama a pantalla completa, controlados en tiempo real desde una tablet mediante un código QR.
- **Seis escenarios predefinidos** para facilitar la demostración.

### Acceso
- [Abrir simulador](https://alejandracardg.github.io/PropuestaFlux/simulador-flux/)
- [Modo presentación](https://alejandracardg.github.io/PropuestaFlux/simulador-flux/?modo=pantalla)

La aplicación funciona directamente en el navegador, sin necesidad de instalar software. La conexión entre dispositivos requiere acceso a Internet.

**Nota:** Los datos utilizados son sintéticos y los resultados tienen fines educativos.
