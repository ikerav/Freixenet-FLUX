# Freixenet FLUX · Simulador organizativo interactivo

Simulador web desarrollado para un proyecto académico de **Diseño Organizativo**. Su objetivo es mostrar cómo podría adaptarse la estructura organizativa de Freixenet ante diferentes situaciones, combinando un modelo predictivo de inteligencia artificial con reglas de asignación de responsabilidades.

## Funcionalidades

- **Simulación de escenarios:** modificación de la demanda, disponibilidad de producto, incidencias logísticas, mercados afectados e incertidumbre.
- **Modelo predictivo de IA:** estimación del riesgo de desajuste en función de los parámetros introducidos.
- **Organigrama dinámico:** visualización de cómo cambia la configuración organizativa y la distribución de responsabilidades.
- **Comparación de alternativas:** análisis de los resultados de diferentes formas de organización.
- **Seis escenarios predefinidos:** demostración de distintas situaciones organizativas.

## Modos de visualización

La aplicación dispone de tres modos:

| Modo | Descripción |
|---|---|
| Simulador | Controles y resultados en una misma pantalla. |
| Presentación | Visualización de los resultados en un ordenador o proyector. |
| Control remoto | Manejo de los parámetros desde una tablet o móvil, con sincronización en tiempo real. |

## Acceso a la aplicación

Una vez activado GitHub Pages, el simulador estará disponible en los siguientes enlaces:

**Simulador completo:**

https://ikerav.github.io/Freixenet-FLUX/

**Modo presentación:**

https://ikerav.github.io/Freixenet-FLUX/?modo=pantalla

Para utilizar el control remoto:

1. Abrir el modo presentación en el ordenador conectado al proyector.
2. Escanear con la tablet o el móvil el código QR que aparece en pantalla.
3. Esperar a que ambos dispositivos establezcan la conexión.
4. Modificar los parámetros desde la tablet y observar los resultados en el proyector.

## Tecnologías utilizadas

- **HTML, CSS y JavaScript:** interfaz y funcionamiento del simulador.
- **Modelo predictivo integrado:** estimación del riesgo directamente en el navegador.
- **PeerJS (WebRTC):** comunicación en tiempo real entre dispositivos.
- **GitHub Pages:** alojamiento de la aplicación web.

La aplicación no requiere instalar software ni ejecutar un servidor propio. Para utilizar el control remoto, ambos dispositivos necesitan conexión a Internet.

## Consideraciones

Este proyecto es una **simulación educativa**. Los datos utilizados son sintéticos y no representan información real de Freixenet.

Las configuraciones organizativas, las estimaciones y los resultados tienen carácter ilustrativo y no deben interpretarse como decisiones reales de la empresa.
